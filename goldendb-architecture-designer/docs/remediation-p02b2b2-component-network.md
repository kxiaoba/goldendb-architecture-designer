## 发现与修正

1. 旧版仅检查网段级端口允许，未绑定具体组件/接口。新增当前组件目录，按实际角色/租户/Group/宿主机/站点生成；导入端点必须引用当前组件及其真实规划宿主机的接口。
2. 旧版可以在无关网段补填复制/管理/备份用途，使实际业务网段承载这些流量却不被发现。已独立复现：原结果结构一致待实测，新结果阻断；原始对照保存before-after.json。现在每条流量用途同时检查两端网段。
3. 新增有向连接与流量引用检查；错误端点/方向、无效端口/资料版本、自连接和重复连接明确诊断。跨租户/共享外部端点需要security证据引用，不自动推断授权。
4. 反向核对每个当前组件的接口映射与连接参与、每条流量的具体连接引用及外部端点参与。用别的组件开放端口不能掩盖未映射组件。外部IP共用或特殊地址保持专项核验。
5. 连接材料纳入版本能力的网络配置绑定。新材料缺项未知，旧材料不会因原通用网络证据通过就自动获得本阶段完整状态。
6. 页面、风险/公式/复制/PNG、固定JSON/HTML/SVG与Excel同源；Excel增加逐组件状态。导入只检查，不调整原数量、角色、分片或落位。
