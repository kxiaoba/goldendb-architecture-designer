## 实施与验证（2026-09-11）

- 新数字框 0 表示跟随机型/总上限；关闭密度时以现有浏览器 2000 实例规模保护作为有限规划边界，不代表产品上限。生产环境忽略 POC 数值与开关，继续同租户 CN 一机一个。
- 单机总上限统计所有租户；同租户上限与总上限同时约束。DN 共宿关闭时同租户上限仍为 1。关闭密度不改变跨租户隔离选项或同 Group 副本跨机规则。
- 统一机型来源可选 CN/DN/GTM/管理。勾选的客户机型优先，否则使用该类推荐硬件；各组件密度仍按自身设置计算。硬件类型统一不会把集群变成一台物理服务器，也不会取消生产全混部红线。
- POC CN 严格筛选合法候选；POC GTM/管理不再使用绕过水位的兜底。CN 未落位提示覆盖 POC；反推缺 CN、控制面或实际资源越界均判不足。
- POC DN 共享策略先平衡同租户实例，再平衡全租户实例；隔离策略先复用已有租户机器，再平衡已占用机器，避免抢占其他隔离租户资源。没有宣称全局最优。
- 本轮共 218 项自动检查通过：专项 28、DN 装箱 25、主分布/说明 61、中心配额 64、XML/导出 40。专项覆盖两模块、1/4 租户、开关、隔离/共享、单一客户 DN 机型、极小资源、生产切换、重置、CN/DN 六实例三主机各两个。
- 响应式 390/875/1600 检查通过；实际两类 PNG 已查看，未见新增遮挡。POC 工作簿 1192 单元格逐格一致，原字符边界工作簿 2889 单元格一致，XML/ZIP 正常；未在原生 Excel/WPS 中验收。
