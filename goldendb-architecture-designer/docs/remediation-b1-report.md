# GoldenDB 修复第一批验证记录

保存日期：2026-09-07。原始基线：`1986f38cf2c1c3779cf4b1c2efffa91bbc62295b`。

## 本批结论

本批实现和测试限于输入边界、无效方案保护、全部重置及相关事件/下载联动。74 项检查通过。不是整个规划工具生产认证，原严格审查的性能一致性、机房角色、装箱兜底、GTM 匹配、资源容量等问题仍需后续批次修复。

## 已保存的修改

| 修改 | 行为 | 影响边界 |
| --- | --- | --- |
| 数字校验 | 空值、非有限值、负数、不合法比例、非整数节点等不再静默变为 0/1 | 当前模块有效输入；未勾选客户机型和非当前模块不阻断 |
| 草稿保留 | 清空 QPS、数据量、CN、Group、副本后保留空值；补全或恢复自动后再计算 | 不改正常数值的性能公式 |
| 无效方案保护 | 清除旧拓扑、推荐数值、服务器分配与公式显示；风险区红色提示；禁止复制、PNG、Excel | 不把上一次方案误当当前方案 |
| 规模保护 | 在实例和服务器展开前拦截非有限/超大结果；限制单次 100 租户、2000 实例/2000 主机 | 浏览器交互保护，不是产品规模限制 |
| 全部重置 | 同时恢复两模块租户、手工节点标志、全局及客户机型默认参数 | 原“重置”按钮明确改名为“全部重置” |
| 跨模块事件 | 忽略隐藏模块旧控件的延迟 change；文本/数字已在 input 更新，不在 blur 二次重绘 | 防止切换模块后刚输入的数据丢失 |
| 下载状态 | PNG 生成过程中参数变化取消旧版下载；Excel 失败后可重试；无效状态不被下载计时器重新解锁 | 保留原 PNG/Excel 输出格式与布局 |
| 编辑器标题 | 两模块租户标题按文本转义 | 仅局部缓解 R11，其他 HTML 输出点尚未完成 |
