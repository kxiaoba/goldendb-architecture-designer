# V3b2 反推净磁盘容量

日期：2026-10-25。V3b2限定范围已本地验收，保留V3b1未提交修改；未提交推送发布。

## 影响与兼容

反推仍为同构库存：统一主机规格应用CN/DN/GTM/管理组件，不引入异构池。新增显式legacy/net选择，默认legacy保持原始reverseDiskTb乘统一预留的旧数值。reverseDiskTb始终是每台原始总盘，不改为净值；net下盘数乘单盘容量必须与总盘一致，不自动覆盖客户原值。CPU/内存继续统一预留，磁盘净口径不再重复扣统一预留。

net复用V3a getDiskCapacity与空间预算：RAID0/5/经典成对双副本RAID10、独立热备、文件系统比例、每主机日志/额外索引/临时空间和独立水位。未知RAID阻止计算，生产RAID0或水位高于本工具80%策略列红线，POC保留提示；不是厂商限制或冗余认证。口径切换保留未启用草稿，重置恢复默认。参考[mdadm md.4](https://github.com/md-raid-utilities/mdadm/blob/main/md.4)的RAID/热备定义，沿用已验收模型，不引入依赖或假定控制器兼容性。

复用统一规格传播到数量估算、资源池/站点、候选布局、逐Group单实例适配、实际落位、水位、摘要/图片及Excel。已知单份数据不额外增长；缺数据需求仍未评估，不能因硬件净容量已知而宣布完整承载通过。空间预算为每主机，仍需用户避免把同一索引/日志同时计入数据量和额外预算。
