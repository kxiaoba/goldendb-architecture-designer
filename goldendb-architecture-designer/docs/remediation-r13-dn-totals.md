# R13 多租户DN副本汇总与手动分片验收记录

日期：2026-10-27；基线eed18e3加已验证未提交R07/R08。只修主页面汇总显示与导出说明，不修改固定数量规划器、计算参数或放置算法。

## 问题事实与算式

输入三个分布式租户，分片24/3/1，副本6/4/5。正确总数为24×6 + 3×4 + 1×5 = 161，而(24+3+1)×max(6,4,5) = 168。修改前两模块实际模型已正确返回161，CPU/内存、实例需求和落位也按各租户计算；不能把本批称为修复161到168的采购数量错误。

真实缺陷是反推页面/公式/复制摘要显示“28 × 6 = 161”，Excel摘要只写“Group数×每Group副本数”而未说明逐租户求和；业务复制摘要将最大副本说成每分片统一副本；旧拓扑角色说明用全局最大值描述所有租户；反推旧风险句将输入最小值到实际最大值说成统一修正。

## 修改

- 新增只读formatDnInstanceSummary，统一“逐租户 SUM(Group × 副本) = 租户1 24×6 + 租户2 3×4 + 租户3 1×5 = 161 个DN实例”，供两模块节点方案、公式、复制摘要、Excel摘要及混合副本PNG使用。
- 最大副本字段继续保留并明确为最大值，不能与总Group数相乘求总DN。混合副本PNG附求和说明，注明规划实例数、实际落位另验、非服务器台数。
- 多租户旧拓扑角色提示显示各租户各自副本数，本站主从以实际落位为准；单租户旧文案保持。
- 删除反推未使用的max乘积局部变量及误导性的全局副本修正句。R08逐租户输入/实际/基线审计保持。
- Excel Group总数说明和业务复制摘要区分实际采用/固定输入/自动建议；不将手工分片称为自动推荐。
