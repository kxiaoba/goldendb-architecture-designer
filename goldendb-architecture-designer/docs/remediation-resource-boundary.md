# R09-C1 服务器资源余额边界

## 计划与原因

- [x] 移除扣除预留后的1核、1GB、0.1TB最低可用容量补值。
- [x] 独立组件估算、混部估算、实际主机水位共用真实余额。
- [x] 预留范围0至0.8，非法值拒绝，不静默限幅；零/负/非有限机型容量拒绝。
- [x] 边界、原功能、实际导出及快照验收。

输入容量×(1-预留)作为统一余额，不先向下取整CPU/内存；实例需求和服务器数量仍按既有规则取整。
例如0.1TB磁盘预留35%后只有0.065TB，不应因补值而容纳0.08TB数据。
64核预留35%为41.6核，而非不同出口分别采用41与41.6。
去除估算向下取整可能使部分临界台数减少，但实际实例装箱仍需按完整实例、密度、反亲和及真实水位检查，不能凭总和估算绕过落位。
