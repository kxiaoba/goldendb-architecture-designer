# R07 预留服务器状态一致性验收记录

日期：2026-10-27；基线：eed18e3；范围：主页面业务测算与资源反推的空预留主机输出。独立固定数量工具保持原逻辑。

## 复现与判断

在反推双中心120台、128核/1024GB测试库存中，92台没有组件且无规格/资源审计；旧页面却显示CPU8%、磁盘0%，Excel将其归为高风险，并逐台形成92条资源红线。原始模型缓存不是有效水位证据。应区分库存待配置和已部署主机资源不通过；不把未知主机当已确认备用容量。

## 修改后的统一规则

|主机情况|状态|显示/处理|
|---|---|---|
|空主机无规格|预留待配置|CPU/内存/磁盘未评估；提示，不逐台阻断既有部署|
|空主机有规格但无审计、审计无效或非零|预留未评估|水位未评估；不能确认备用或重建容量|
|空主机规格和零占用审计齐全|空闲预留|显示账本0%；提示，不能等同接管/重建或性能认证|
|有组件缺规格/审计/水位字段|未评估|部署红线；反推结论及PNG明确不可作为可用方案|
|有组件资源超限或需求异常|未通过|保持高风险及部署红线；真实110%超限仍显示|
|有组件DN数据需求未提供|部分未评估|既有口径保持：不能确认完整磁盘；Excel磁盘保留未评估，页面补已录入部分说明|

状态、严重度和水位显示复用同一函数，覆盖物理清单、反推清单、拓扑、公式/复制文本、PNG及Excel。空预留主机汇总说明不能计入已确认容量；有组件超水位不依赖旧缓存红线。原始数量、规格、落位、资源状态及评分输入不变。
