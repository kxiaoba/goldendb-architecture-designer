# P02b2a 双栈网络与实际库存容量验收

完成：2026-10-30。接续 2026-10-29 中断工作副本，基线为 d591ab9 加已验证的 P01/P02a/P02b1 未提交修改；170 文件修改前快照保持。当前状态以 checkpoint.json 为准。

## 本批发现与修改

1. 旧库存只验证数值合法性，未核对当前规划资源需求。复现：1物理核实际库存面对8物理核规划，旧检查仍“结构一致待实测”；新检查明确阻断。原始对照保存在 before-after.json。
2. 新增明确 GB/GiB、TB/TiB、物理核、CPU/内存预留与数据净盘水位映射。每主机逐资源独立检查，磁盘未知不能隐藏已知CPU不足；已扣水位不得二次扣，原始需求不二次减预留。
3. 固定数量工具缺资源需求，明确未评估，不按零；不完整需求只检查已知部分。单位缺失、超安全数值范围均不自动通过。
4. 新增严格 IPv6 解析、前缀范围、地址族、数值去重和网段重叠检查；不错误使用IPv4广播规则；/127、作用域/映射地址、跨地址族流量保留适用性检查。
5. 页面与Excel增加逐主机容量详情；固定JSON/HTML/SVG、风险、复制与PNG保持相同门禁。验收中发现库存容量与原有容量证据同分类导致行数混合，已分为 inventory-capacity 与 capacity，并复测。
