## 审计边界

- 单机失效，恢复到既有幸存同AZ/池；不模拟更换坏机后回原盘重建、不迁移已有实例、不自动扩容或改变副本数，不将“当前无空位”当作业务必然中断。
- 最多200台库存、80个DN宿主机失效场景、1000个已落位组件；每故障最多32个丢失DN，整次最多20000次试放。超过预算为未评估，不能声称数学上无解。
- 若在上述有限目标集合中穷尽组合且没有解，报告该集合存在缺口；不外推为更换硬件、重新平衡或跨AZ策略也不可行。
- 旧磁盘口径与工作区声明仍只是预算。源可读性/日志位点、复制追平、控制面、厂商重建策略、并发IO/网络、实际空间开销、恢复时间及RPO/RTO保持未评估。
- 源/目标预算非法或身份异常不乐观计入。空预留主机缺规格不自动借容量；原R07专门整改仍保留。
- 60台固定数量入口保持原结构结果；该入口缺硬件/数据/负载，不能套主工具的资源审计冒充重建通过。
