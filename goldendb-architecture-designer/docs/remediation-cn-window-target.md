## 实现与独立复算

令D为增长后的平均处理目标，W为窗口秒数，P为停顿秒数，e为并行效率，r为额外重试比例，L为输入不可用CN数，k为标定每核能力，w为单次安全水位系数。

- 总工作量A = D * W * (1+r)，不再重复乘增长。
- 剩余处理时间S = W-P。显式N+1生产要求S>0，否则保留输入但阻止生成有限方案。
- 反算持续吞吐B = A / (S*e)。B不是峰值，也不回写原始平均需求D。
- 预留R = max(1,L)，与实际窗口审计的独立故障max口径保持一致，不把两个同类损失相加。
- 按允许核数上限C推荐n = max(2,ceil(B/(C*k*w))+R)，再应用原偶数规则。
- 自动规格按n-R个实例分担B，仍受原单机核数/内存上限限制。手动数量和规格保持，若余量不足则保留红线。
- 实际落位故障时长 = A / ((有效CN-max(L,单台物理机最多CN数))*c*k*w*e) + P。无剩余吞吐记为无法完成，不输出Infinity。

本批共享readBatchWindowParameters参数校验，供推荐和原窗口审计使用。水位已含安全余量时w=1，不再次折减；效率也不重复乘入标定。显式N+1且启用总量/窗口校验才采用新反算；原audit、normal、POC、峰值模式和未启用窗口的数量公式保持。

旧案例3CN只剩1个有效CN，预计6336000/280+1800=24428.571秒，大于7200秒。新推荐7CN剩5个有效CN，预计6336000/1400+1800=6325.714秒，小于7200秒。SQL总次数口径先独立转TPS再使用同一工作量模型，不把业务单位当作TPS。

窗口审计新增统一error：仅生产容量中心的正常窗口不足，或生产环境要求故障余量而单机故障窗口不足才进入相应红线；POC单机故障不足、灾备全量接管参考、normal的额外故障不足保留中性提示。normal和POC不取消用户明确输入的L造成的正常窗口不足。页面样式与Excel红线共用error，不能把中性提示显示为已通过。

单场景非法故障策略进入原PlanningInputError校验，拒绝被旧全自动路径静默忽略。原窗口专项支持独立输出目录，避免覆盖历史证据。
