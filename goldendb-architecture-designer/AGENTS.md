# GoldenDB 修改与续接约定

- 每次修改前读取 `docs/remediation-progress.md`，确认当前批次、已完成项和遗留项，勿重复实施或覆盖用户修改。
- 遵循 `code-change-safety` 技能：先评估输入、计算、装箱、校验、组网、摘要和导出的影响，再做局部修改与回归测试。
- 本轮用户批准执行严格审查 R01–R18；详细依据见进度文档。不得把规划示例、线性估算或未评估指标写成厂商性能/生产高可用承诺。
- 每批完成后保存代码、测试结果、变更记录及下一步；遇到中断也更新进度，明确未验证内容。
- 未明确收到本轮提交/推送/发布指令，不执行 Git 提交、远端推送或 Pages 发布。
